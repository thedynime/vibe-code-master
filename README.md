## 🌟 Why Vibe Code Master?

Modern AI coding assistants (Google Antigravity, Anthropic Claude Code, OpenAI Codex, Cursor AI, Windsurf) are only as powerful as the context, runbooks, and domain constraints provided to them.

**Vibe Code Master** packages over **290+ audited agentic skills**, **12 specialized plugins**, **hardened MCP servers**, and **universal security & visual quality guardrails** into an instantly deployable repository.

- 🎯 **Anti-Generic UI Taste**: Hard bans on default purple/blue AI gradients, boring symmetric cards, and fake testimonials. Enforces haptic micro-interactions, editorial typography, and fluid spring motion.
- 📉 **Universal Token Optimization**: Progressive disclosure protocol keeps instruction entry points under 8 KB while routing complex workflows to specialized modular skills.
- 🛡️ **Claude Security Active Protocol**: Scanned code is treated as data, credentials are strictly masked, and fixes are delivered as verified patches.
- 🔄 **Always Up-To-Date**: Built-in automated synchronization script continuously ingests new skills, plugins, and optimizations directly from your local workspace.

## 🚀 Quickstart Installation

### 1. One-Line Instant Install (macOS & Linux)
Install all skills, plugins, rules, and scripts directly into your global agent environment (`~/.gemini/config/`):

```bash
curl -fsSL https://raw.githubusercontent.com/thedynime/vibe-code-master/main/scripts/install.sh | bash
```

### 2. Clone & Sync Locally
```bash
git clone https://github.com/thedynime/vibe-code-master.git
cd vibe-code-master
./scripts/install.sh
```

## 🔄 Continuous Auto-Sync (Keep Everything Updated)

Whenever you add, modify, or customize any skills, plugins, or rules in your local workspace, run a single command to sync, catalog, commit, and push everything to GitHub automatically:

```bash
# Using bash script
./scripts/sync.sh

# Or using npm
npm run sync
```

What the sync engine does:
1. Scans `~/.gemini/config/skills/`, dereferencing symlinks into self-contained standalone folders.
2. Ingests all active plugins from `~/.gemini/config/plugins/`.
3. Sanitizes MCP configs, redacting private credentials into environment variable templates.
4. Updates cross-platform rules (`GEMINI.md`, `AGENTS.md`, `CLAUDE.md`, `.cursorrules`).
5. Creates a timestamped git commit and pushes directly to `main`.
