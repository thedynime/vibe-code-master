21st.dev MCP Server.
Search and inspect ready-to-use React/Tailwind/Framer Motion UI components, themes, templates, logos, and video blocks.
Key tools:
- `search`: Search components across 21st.dev library.
- `get_component`: Retrieve full source code and demo for a component.
- `get_theme`: Retrieve 21st theme specifications.
- `search_logo`: Search SVG brand logos.
- `get_inspiration`: Find design inspiration and UI patterns.
