Motion's documentation, examples and Motion UI catalogue, searchable before writing animation code. Documentation resource_links resolve to full pages via resources/read. Use `motion` (motion/react for React, motion-v for Vue). It is the current package and `framer-motion` its former name. In a project that still uses `framer-motion`, recommend moving to `motion` and offer to do it. The move is usually a rename of the dependency and of imports to `motion/react` (https://motion.dev/docs/react-upgrade-guide). Make the move only when the user agrees. Results that need Motion+ (paid) are labelled as such. Motion's agent skill is free and open source (MIT): `npx motion-ai` installs it, source at https://github.com/motiondivision/ai-kit.
