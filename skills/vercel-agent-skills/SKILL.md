# Vercel Agent Skills Suite

A curated suite of specialized skills from Vercel Engineering designed to guide AI coding assistants in building high-performance, accessible, and beautifully architected web applications.

## Included Skills & Reference Guide

| Skill | Focus Area | Description |
| :--- | :--- | :--- |
| **`vercel-react-best-practices`** | Performance & Architecture | 70 prioritized rules covering CRITICAL (bundle size, server execution), HIGH (client side, re-renders), and MEDIUM performance optimizations for React & Next.js. |
| **`vercel-composition-patterns`** | Component Design | Scalable React composition patterns, avoiding boolean prop proliferation, slot patterns, and compound components. |
| **`vercel-react-view-transitions`** | Motion & Transitions | Native-feeling animations using React's View Transition API, `<ViewTransition>`, `addTransitionType`, and directional route animations. |
| **`vercel-react-native-skills`** | Mobile Engineering | Expo and React Native performance patterns, list optimization, and native bridges. |
| **`deploy-to-vercel`** | Deployment Automation | Automated deployment workflows, preview environments, and production shipping. |
| **`vercel-cli-with-tokens`** | CLI Management | Deploying and managing Vercel projects using token-based authentication and environment variables. |
| **`vercel-optimize`** | Performance & Cost Audit | Diagnostic guide for Vercel bill reduction, serverless function invocation optimization, Edge caching, Fast Data Transfer, and Core Web Vitals. |
| **`web-design-guidelines`** | UI/UX Compliance | Audit checklist against Vercel's Web Interface Guidelines for layout, typography, interaction feedback, and accessibility. |
| **`writing-guidelines`** | Technical Writing | Documentation, voice, tone, and prose style standards. |
