# Creative Director Design Package Template

Input document produced during Phase 5 and consumed during Phase 8.

```markdown
# [Project Name] Design Package

## 1. Brand Foundations
- **Premise / Core Metaphor**: (e.g., "The slow, deliberate drip of cold brew in an underground cellar")
- **Palette Tokens**:
  - Primary Background: #0B0D11
  - Hero Accents: #D97706, #F59E0B
  - Text Light: #F3F4F6
  - Text Muted: #9CA3AF
- **Typography**:
  - Display Font: Syne / Cabinet Grotesk / Clash Display
  - Body Font: Plus Jakarta Sans / Inter
  - Accent / Meta: JetBrains Mono

## 2. Scroll Story & Beat Map
- **Track Length**: 350vh - 500vh
- **Band 0 (0% - 15%)**: Hook & Initial Descent
  - Headline: "Ten dashboards. Zero answers."
  - Negative Space: Top-left calm quadrant
- **Band 1 (25% - 50%)**: Tension & Shift
  - Headline: "Until the noise cleared."
  - Scrim: Radial soft dark
- **Band 2 (60% - 85%)**: Resolution & Arrival
  - Headline: "One clear path. Finally."
- **Settle Frame (90% - 100%)**: Final resting position where page docks into lower sections.

## 3. Lower Page Architecture
1. **Proof & Value Metric**: 3-part grid with matching supporting imagery.
2. **Interactive Moment**: Designed slider / toggle / interactive element.
3. **Objection Buster & FAQ**: Addressing real buyer friction points in plain language.
4. **Final CTA & Form**: Single conversion funnel.
```
